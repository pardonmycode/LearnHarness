So sieht aus, was der Lernserver an die KI schickt. Die festen Regeln stehen im Code (server/tutor/harness.py); eigene Ergänzungen tragen Sie in den KI-Einstellungen ein. Was tatsächlich hinausging, steht im KI-Protokoll.

Schutz durch den Harness

  • Aktiv: {{ settings.get_provider_display }} – {{ settings.active_model|default:"kein Modell eingetragen" }}
  • Code in Tutor-Antworten: höchstens {{ settings.max_code_lines_in_chat }} Zeilen am Stück. Längere Codeblöcke (auch ohne ```) werden noch während des Streamens ersetzt durch: „{{ replacement }}“
  • Übungen: Die KI liefert Aufgabe und Lösung getrennt; das Kind bekommt nur die Aufgabe. Ob die Antwort stimmt, prüft der Server selbst.
  • Code nach richtiger Antwort: höchstens {{ settings.max_changed_lines }} geänderte Zeilen, nur in die geöffnete Datei, mit erklärenden Kommentaren. Mehr wird abgelehnt (ein zweiter Versuch, dann ohne Code).
  • Anfragen: höchstens {{ settings.requests_per_minute }} pro Kind und Minute.
  • Eingaben der Kinder stehen in <kind>…</kind> und gelten für die KI als Inhalt, nicht als Anweisung.
